<Dialog v-model="dialog"></Dialog>

# 对话框属性

属性名 描述说明 类型 默认
v-model 是否显示框 - -
auto-height 对话框高度自适应 Boolean true
height 对话框高度(若大于 0 则使用 height) Number 0
close-text 关闭按钮文案 String 关闭
confirm-text 提交按钮文案 String 确定
popconfirm-text 确认按钮提示文案 String -
full-screen 是否全屏显示 Boolean false
destroy-on-close 关闭弹框后是否销毁 Boolean false
enable-button 是否显示弹框所有按钮 Boolean true
enable-close 是否显示关闭按钮 Boolean true
enable-confirm 是否显示确认按钮 Boolean true
enable-escape 是否启用 Escape 关闭弹框 Boolean true
enable-click-modal 是否点击弹框以外关闭 Boolean false
enable-popconfirm 是否启用确认提示 Boolean false
loading 确认提交按钮状态 Boolean false
delay 自适应高度的延迟变化时间 Number 0

# 对会框插槽

插槽 描述说明
header 对话框标题部分
footer-button 底部默认按钮最左边
footer 对话框底部按钮, footer-button 之后
footer-button-between 关闭和确认按钮之间
