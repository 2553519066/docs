# <Pagination />

组件继承了 element-plus el-pagination 所有属性, 并扩展了更多属性

<Pagination :total="100" :page-size="[10, 20, 50, 100]" :current-change="1" justify-content="center" @size-change="onSizeChange" @current-change="onCurrentChange">
  <template #left>插槽</template>
  <template #right>插槽</template>
</Pagination>

# 属性

属性名 描述说明 类型 默认值
current-page 当前页 Number 1
page-size 每页显示数 Number 10
page-sizes 每页显示数量 Array [10, 20, 50, 100, 300, 500]
total 总数 Number 0
justify-content 分页位置, 同 Css, String flex-end
layout 分页布局 String total,sizes, prev, pager, next, jumper

# 事件

属性名 描述说明 类型
size-change 分页数量发生变化时 Function(size)
current-change 当前页发生变化时 Function(page)

# 插槽

插槽 描述说明
left 左插槽
right 右插槽
